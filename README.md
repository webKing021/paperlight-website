# Paperlight website

The landing page for [Paperlight](https://github.com/webKing021/paperlight), the free Windows app
that finds any document on your PC.

Built with Vite, React, TypeScript and Tailwind CSS. No backend, no tracking.

## Run it

```bash
npm install
npm run dev
```

`npm run build` creates the production site in `dist/`.

## Deploy on Vercel

Import this repo in Vercel and press **Deploy**. `vercel.json` already sets everything up,
including a fallback so no page ever shows Vercel's 404.
